# 配乐交付规范

## 默认出片

成功源片不作音频、对白、口型、响度、人声余量、可闻度或卡点品质评审。不自动分离、ASR/TTS 或品质重混；按请求配乐/保留策略实际加工一次，`qualityReviewed=false`。原节目音无需签发密钥；明确给定签章分轨才严格验证该引用，不丢弃错误来源。

## 实际产物

| 项目 | 合同 |
|---|---|
| 文件 | 新路径与版本，不覆盖输入；最终文件真实存在并带 SHA-256 |
| 视频 | 视频轨 copy，不为配乐重编码画面；记录实际规格与轨道 |
| 音频 | 请求混音参数实际执行，输出轨道和时间轴符合本次工程请求 |
| 短音乐 | 有限 WAV 先物化，记录真实循环次数与时间轴摘要 |
| 声学品质 | `levels`、响度前后、人声余量、可闻度等未测值为 `null`，不能称已通过 |
| 来源 | 默认 `original-program-bytes` / `stemsVerified=false`；显式分轨照验签章/作用域/时限/字节 |

## 输出契约

每次记录源/音乐/实际产物路径与 SHA-256、配方/曲目 id、许可和所需 TASL 署名、实际保留策略与电平/让位/淡入淡出参数、真实时长/轨道/编码、时间轴加工与工具指纹。明确选段时另附真实起止秒数与依据。没有执行的诊断不制造波形/品质图和指标。

## 版本、回滚与围栏

源片只读（G-BGM2），产物版本只增；品牌主题曲/首次许可使用保持前置审查（G-BGM1），配额与版权保留（G-BGM4/G-BGM5）。旧 `verify=false` / `skip_verify=true` 不作质量阻断；弃原声必须明确请求 `allow_discard_original=true`（G-BGM3），显式分轨仍遵守其角色合同。

## 返修

用户明确反馈电平、配方、让位或选段时，先做影响分析，按其请求重算音频层并记录真实行为，不重生成镜头。默认不会因工具品质分数、静音或听感判断再跑一遍。实际 FFmpeg、文件、许可、权限或字节错误明确失败，保留回执，不把草稿改成完成。

历史 `library/bgm-kb/` 阈值仅供显式诊断参考，不是当前默认交付闸。
