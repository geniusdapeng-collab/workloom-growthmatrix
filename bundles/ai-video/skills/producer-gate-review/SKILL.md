# 监制门评审（Producer Gate Review）

## 适用范围

- **新生成前**内部准备门：G1 情报、G2 主题、G3 对齐、G4 PRD、G6 提示词、G7 预生产收口。
- G5 仅针对本次新建的定妆资产，默认人类验收；机器像不像只作留证，不自动重做，也不能代签。
- **成功渲染直接正式后期**：`shot/compose/color/subtitle/danmaku/bgm/sfx/cover/mux/master` 调用共享 `post-render-acceptance.ts`，不走模型或人类源片品质评审。

## 新生成前方法

1. 核对完整需求、属性/授权、商品来源、预算与支付，以及新生成输入是否真实、完整、可读取。空内容、占位符、缺新生成必需定妆资产等按当前预生产合同失败，不让模型代替授权事实。
2. 预生产内容需仲裁时按当前 `PRODUCER_RUBRICS` 和受控参考进行准备评审。环境、道具与设备要求落在新生成镜头卡，不在成功源片上重新抽帧判合格。
3. 打回即停，写明可执行修正与依据；不默认同提示词重试。是否再生成按本次需求与授权决定。
4. 记录 `gate/score/via/model/degraded/issues/suggestions`；模型不可用时按当前预生产降级/失败策略如实留证，不能改写为模型已审核。

## 前置校验

1. 必须先按真实供应商 task、项目/镜头/源请求和当前字节分出已完成片段与待新生成片段；只对待新生成集合执行准备和提交门，不能把已成功片段重新加入 G5/G6/G7。
2. 待新生成必须具备本次身份/肖像、商品、品牌、预算和支付等事实授权；模型评价不得代签，不得凭旧成功片段给另一笔新生成授权。
3. G5 新建定妆资产必须保留人类验收事实；不是本次新建的已成功影片不通过 canary 或源片抽帧重新放行。
4. 后期必须核对源路径、当前摘要、真实输出路径和请求工位；源缺失、摘要变化、供应商真实失败或加工失败，不得仅改裁决字段继续写完成回执。

## SOP 与留痕

1. **触发**：收到影片任务或断点续作；计算待新生成集合和可复用成功片段。**回执**：project/shot/source/task/字节绑定、实际复用范围。**失败**：真实任务归属或字节不符，停止对应片段，不把历史品质状态当成功证明。
2. **触发**：确有待新生成片段；执行上节前置校验与对应准备门。**回执**：真实授权、门裁决、模型/人审使用事实。**失败**：缺必需事实或打回，停在提交前，说明修正位置，不自动烧额度重试。
3. **触发**：成功片段进入后期；按正式工位实际加工一次。**回执**：输入/输出 SHA-256、实际工位、请求规格与错误。**失败**：工具/字体/文件/导出错误返回技术失败，保留原片和历史行。
4. **触发**：汇总阶段；分别记录未调用、复用、实际执行与失败。**回执**：后期 `score=null`、`rerun=false`、`qualityReviewed=false`。**失败**：缺真实产物不得写已交付，未调用模型不得写模型已审核。

## 成功镜头与正式后期方法

1. 复用同项目、同镜头、源请求、真实成功 taskId 与原文件 SHA-256。旧品质 `failed/score=0` 或代码配方变化不触发重生成；旧行保持原样。
2. 不对源片人物、服装、动作、原始尺寸/帧率/精确时长、黑画面、音频、台词、口型或 canary 做评分、抽样、模型/人类二次放行；不由其触发 ASR/TTS、重渲染或后期选优返工。
3. voice 默认沿用源节目音；只有用户明确要求统一旁白才执行实际配音，失败按工具错误返回。成功无音轨片段也可进入实际合成，不编造原人声。
4. 实际调色、字幕、弹幕、配乐、封面和请求变体各加工一次。保留 ASS/font/timeline、来源摘要、请求输出画布、轨道、路径/命名与真实编码/文件/取件错误。
5. 裁决为 `score=null`、`rerun=false`、`qualityReviewed=false`。通过表示工位实际文件与加工技术接收，不表示品质已合格。

## 输出契约

预生产评审沿用 `{approved,score,hardFailures,issues,suggestions,rerun,via,model,ms,reason}`。正式后期的 `score` 为 `null`、不调用模型，附实际产物摘要与范围。全链路记录在 `<work-dir>/logs/stages.jsonl` 与 `stage-summary.json`，保留真实失败、未调用、复用与实际加工信息；不能只改报告让失败变成功。

## 失败与边界

| 情况 | 原因/检测器 | 处置 |
|---|---|---|
| 新生成必需事实缺失 | 待新生成集合的需求/授权/支付/商品来源校验失败 | 提交前失败，保留事实与原请求 |
| 供应商真实 failed/rejected 或归属不符 | 任务回执、taskId、项目/镜头/请求绑定不一致 | 不能复用为成功源片，也不由旧品质记录覆盖供应商失败 |
| 源文件无法取用 | 路径缺失、SHA-256 变化或普通元数据读取失败 | 返回技术失败，无品质重试 |
| 工位加工失败 | 实际 FFmpeg、字体、ASS、导出或取件错误 | 失败回执保留，只修对应工位，不声称已交付 |
| 旧品质失败或源片看起来不佳 | 成功供应商任务与原始字节仍匹配，只有历史品质裁决失败 | 原记录保留，成功任务按字节直接后期；不自动重生成 |
| 明确请求统一旁白或更换画面 | 用户请求与本次真实授权记录 | 按真实授权执行独立加工/新生成，记录具体动作与费用 |

本技能不替代新生成花钱门、发布/评论等对外门，也不把模型判断当身份授权。显式独立诊断接口可以记录诊断；默认影片接收与后期不调用它们，不受诊断分数阻断。
