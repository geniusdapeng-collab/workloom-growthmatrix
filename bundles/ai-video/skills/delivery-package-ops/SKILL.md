# 交付包与多风格变体

## 当前产品口径（2026-10-07）

成功供应商镜头默认接受并进入正式后期，不评人物、服装、动作、原始规格、黑画面、音频、对白、口型或画质，不因旧品质失败或新组件配方重生成。按本次请求加工一次；`qualityReviewed=false`，品质分数和画面/音轨/封面差异指标为 `null`。不能把真实文件存在或不同配方写成品质通过。

## 请求到交付

1. 读取镜头文件、真实 task/源摘要与当前字节；旧品质失败历史保留。缺文件、错误供应商任务或字节不符明确失败。
2. 按工程请求实际归一化画布、帧率与时间轴，合成干净母版。成功源片原始规格不是品质闸；HD/UHD 使用真实 FFmpeg scale/pad，不强制模型增强。
3. 按请求变体各执行一次拼接、调色、配乐、封面与文案。内置三种配方可选；显式只请求一支也可完成。G-DLV1 只阻断所请求变体缺产物。
4. 字幕默认旁挂；软字幕执行 `-c:v copy -c:a copy`，保留实际命令、轨道元数据、时间轴与摘要，不默认逐帧或 PCM 品质评审。硬字幕仅按明确请求另存副本，母版不烧字（G-DLV2/G-DLV3）。
5. 写工程、清单与真实加工报告，所有文件提供 SHA-256；请求层加工失败不能降级为整包成功。

## 交付产物

| 产物 | 路径 | 说明 |
|---|---|---|
| 干净母版 | `master/master-clean.mp4` | 未烧字幕的返修地基 |
| 旁挂字幕 | `subtitles/*.srt` / `*.ass` / `*.vtt` | 字体、ASS 与请求时间轴可核对 |
| 变体成片 | `variants/<id>/<id>.mp4` | 本次请求的真实配方与实际成片 |
| 软字幕轨版 | `variants/<id>/<id>.softsub.mp4` | 实际流复制和可开关字幕轨 |
| 硬字幕副本 | `variants/<id>/<id>.burned.mp4` | 仅明确请求时产出 |
| 封面、文案、音频回执 | `variants/<id>/` | 请求参数、来源、许可、文件摘要；无默认品质分 |
| 工程与清单 | `film-project.json` / `delivery-manifest.json` | 层结构、相对路径、真实配方、复用证据与成本 |
| 人看说明 | `delivery-report.md` | 实际文件、加工结果、返修路径与真实失败 |

## 默认音频与显式来源

无显式签章分轨时使用原节目音，无音轨按请求时间轴补静音；不自动分离、ASR/TTS 或声学评分。显式分轨引用必须重验租户、范围、签名、时限和所有字节；错误引用不丢弃后改走默认。曲目许可/署名照验；丢弃原声必须来自明确请求。

## 返修与权限

反馈先由 `postread.impact` / `postwrite.triage` 归因，`postwrite.reedit` 只重算受影响层。字幕、配乐、调色、封面和文案变更在本地解决；用户明确要求改画面时才提出逐镜新生成计划，经过 G8 前置授权，不由品质评分触发。复用带真实 SHA-256 与未重算事实（G-DLV7）；清单和工程不可缺（G-DLV6）。版本只增不覆盖，前置版本/hash 并发冲突明确失败。

## 输出契约与失败

源文件只读，所请求产物必须真实存在且规格/轨道符合工程请求；实际 FFmpeg、文件、路径、权限、字体、许可、配额或存储错误返回真实失败并留痕。不得以未測品质值冒充通过、用原声草稿冒充请求配乐完成、编造模型增强或复用来源。

成本按本次真实行为记录：仅本地派生写 `shotGeneration=reused` / `tokenCostDelta=0`；另有明确新生成请求时另记真实额度。
