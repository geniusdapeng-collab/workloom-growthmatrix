# 字幕烧录执行纪律

## 当前默认（2026-10-07）

成功源片默认接受，字幕/标题按请求加工一次，不抽帧评可读性、字号、墨迹、安全区、对比度或字幕可现度，不因旧 `verify` / `skip_verify`、布局偏好开关阻塞。不用品质判据删字幕或抽稀弹幕；未测品质为 `null`、`qualityReviewed=false`。

母版默认不烧字。先产旁挂 `srt/ass/vtt` 与清单；软字幕轨实际执行视频/音频 copy 并记录轨道/元数据/时间轴与摘要，不默认逐帧或 PCM 品质检测。只有明确请求才另存烧字副本，源母版只读。

## SRT 与 ASS 加工合同

| 项目 | 行为 |
|---|---|
| 时间轴 | 合法起止/条数按请求保留；非法格式、倒挂或实际越界明确失败 |
| 多行 | 同 cue 多行按 ASS `\N` 编码，长行由 libass 排版，不以字数品质裁内容 |
| PlayRes | 按实际请求画布生成 |
| 字体 | 指定/选型字体实际可读取，记录字体 id/文件摘要与 fontselect；缺字体或系统回落错误明确失败 |
| 音轨 | 字幕加工保留实际原音轨；无音轨不强求存在 |

## 六类实际加工

| 轨 | 执行与记录 |
|---|---|
| 字幕/标题 | 请求字体、样式、文字与时间轴一次渲染；记录实际 ASS 与产物 |
| 弹幕 | 保留所有请求事件；密度事实可记，不按密度抽稀或品质退回 |
| 贴纸/花字 | 请求合法时间与位置实际加工，不用建议停留/安全区作品质否决 |
| 卡拉OK | 实际 `\kf` 时间轴；缺逐字发音时间则按字数均分并标“非真实发音对齐” |
| 双语 | 保留主/次语言实际时间轴与请求样式 |
| 旁挂/软轨 | 只写字幕文件或实际流复制，清单如实记录 |

## 输出契约

源/产物 SHA-256、实际 ASS/字体与解析日志、事件条数/时间轴、编码器、实际规格/轨道、真实请求参数与执行错误。源字节必须保留；实际产物存在且符合请求规格，不默认出品质证据帧。字体许可与品牌前置授权照验。

## 失败与围栏

G-SUB2 保留覆盖源文件禁令；G-SUB3 只阻真实字体/ASS/时间轴错误；G-SUB6 只阻非法事件时间；配额（G-SUB4）与许可（G-SUB5）保持。真实 FFmpeg、文件、路径、权限、存储或输出错误明确失败留痕，不根据源片或后期品质分数重生成/重试。

## 前置校验

1. 必须明确本次是旁挂、软字幕轨还是硬字幕副本；不得把“提供字幕”理解为改写母版，硬烧只由明确请求触发。
2. 必须保存完整字幕/标题/弹幕事件、语言和请求时间轴；非法格式/起止返回输入错误，不静默丢条、截断文字或抽稀事件。
3. 必须核对真实字体文件、许可和解析目录；缺字体、ASS 编码或实际 fontselect 回落错误不能用“视觉通过”掩盖。
4. 必须使用新输出路径、正确请求画布和可写存储；禁止覆盖源文件，执行前记录源 SHA-256，执行后核对未变化。

## SOP

1. **触发**：收到文字轨请求；解析完整输入与输出模式。**回执**：原事件条数、语言、起止和源摘要。**失败**：`bad_srt`/`bad_style` 保留条号与原值，停止该输出。
2. **触发**：事件有效；生成 SRT/ASS/VTT 或实际烧录方案，选择真实字体。**回执**：文件内容、PlayRes、样式、字体摘要。**失败**：字体或 ASS 不具备，返回错误，不以系统字体/空字幕冒充请求。
3. **触发**：请求软轨或烧录；执行一次真实 copy/渲染。**回执**：实际命令、fontselect、编码器和媒体轨道。**失败**：非零退出、超时或存储错误，保留错误日志，不通过改请求内容继续。
4. **触发**：工具结束；核对本次产物、时间轴和源字节并写清单。**回执**：真实文件 SHA-256，未测品质为 `null`。**失败**：无文件、旧文件或请求轨道缺失，不能写成功回执。

## 失败诊断：原因与处置

| 症状 | 原因/检测器 | 处置 |
|---|---|---|
| SRT/事件无法解析 | 错误时间格式、倒挂、非法弹幕或逐字起止 | 返回真实条号和 code；修输入，不删条假成功 |
| 字体没有实际加载 | 字体不存在/不可读或 fontselect 显示回落 | 保存解析日志；修字体目录/许可或明确更换请求字体 |
| ASS/FFmpeg 执行失败 | 错误转义、样式、滤镜、编码器或真实非零退出 | 保留 ASS 和错误日志；修对应工位后以新请求加工 |
| 写出或取件失败 | 权限、配额、磁盘、缺输出或轨道不符 | 返回真实失败；不交旧文件，不只修改报告 |
| 品质值为 null | 默认未执行墨迹/对比度/可现度诊断 | 如实标未测，保留真实加工回执，不触发源片重评 |
