# 题材与场景调色设计

## 默认选择（2026-10-07）

成功源片直接后期。用户明确 profile/LUT/强度优先，其余依据请求题材、场景、情绪与平台元数据从 `colorread.recipes` 取固定配方；`colorwrite.best` 也执行一次固定配方，无源片画质候选评分或“未超过+2分就不出文件”。

## 创作建议

| 内容/意图 | 配方方向 |
|---|---|
| 产品/教学 | clean-bright / natural，准确克制 |
| 叙事/情感/美食 | warm-film，温暖 |
| 技术/汽车 | cool-technical，冷净 |
| 悬疑/高端品牌 | moody-dark，克制 |
| 社媒促销 | high-contrast-social |
| 怀旧 | vintage-fade |

可通过 `colorread.recipes` 读取真实配方、LUT与建议参数；不凭空 invent 路径。以上是选型建议，不以源片肤色、曝光、亮度漂移、模糊、裁切、品牌色像素差或调色可见性作默认品质否决/退回/重生成。

## 实际加工

请求层只加工一次，留真实 profile/LUT/强度/滤镜与工具回执。明确要求参考匹配才调用 match，明确诊断才运行 analyze/scope；它们不是成功源片默认前置条件。不用品质分数追加参数校正重试。

## 输出契约

题材/场景/平台/用户请求、配方 id、实际 profile/LUT/强度/滤镜、源/产物 SHA-256、实际规格/轨道与执行错误；`qualityReviewed=false`，未测画质、前后差异或缺陷值为 `null`，不称不同配方为品质通过。

品牌默认 look 变更前置授权、路径/租户/权限/许可/配额、源只读与真实 LUT/FFmpeg/文件错误继续生效。用户明确改风格时按返修请求重算，不由源片质量自动触发。

## 工艺判据与配方落地

| 决策输入 | 实际动作 | 回执依据 |
|---|---|---|
| 明确指定 profile | 使用请求的仓内 profile，不再替换成评分赢家 | 配方 id、实际滤镜链 |
| 明确指定 LUT | 读取真实 LUT 文件并记录摘要；转换 LUT 先于创作 look | LUT 路径、SHA-256、滤镜顺序 |
| 只有题材/情绪 | 用上表方向查询 `colorread.recipes`，选择匹配清单首个确定配方 | 请求元数据、命中配方、选择理由 |
| 指定强度 | 创作 look 按有限值 `0 < intensity ≤ 1` 混合；校正/转换不是同一强度层 | 请求强度、实际链中混合系数 |
| 明确参考匹配 | 单独执行 `colorwrite.match`，保留参考与每个目标摘要 | 匹配请求、实际校正参数、输出文件 |
| 明确诊断 | 单独读取 analyze/scope 的测量事实；默认加工不自动调用 | 诊断请求、测量值及不可测原因 |

## 参数边界

1. `intensity` 必须是有限值并落在 `(0,1]`；非法值返回 `bad_request`，不偷偷改成默认值。该范围来自 `color-bridge/core.mjs#buildChain`，属于可执行参数合同。
2. profile/LUT 必须来自真实索引或明确可读取文件；不得用不存在的路径代替风格名，也不得在缺 LUT 时冒充已经套用。
3. 原片只读，输出必须是不同的新文件；禁止覆盖原片。租户、资产根和品牌默认 look 授权在执行前核对。
4. 不得按源片亮度、肤色、模糊或差异分数阻挡成功源片；建议配方与设计偏好只能影响未指定参数的选择。未做的测量必须记 `null`。

## SOP

1. **触发**：收到调色或更换 look 请求；读取源文件、目标输出和明确参数。**回执**：请求参数、源 SHA-256、实际元数据。**失败**：源缺失或越过资产根，返回真实错误，停止此工位。
2. **触发**：请求未指定配方；按题材/场景查询配方索引并固定一次选择。**回执**：配方 id、LUT/profile/强度与选择依据。**失败**：配方/LUT 缺失，返回未找到，不以源片评分另选或重试。
3. **触发**：参数合同和前置授权具备；执行一次实际 grade 或明确请求的 match。**回执**：滤镜链、编码器、源/产物摘要及真实规格。**失败**：FFmpeg 非零退出、文件写入或规格错误，保留失败原因，修该工位后以新请求重算。
4. **触发**：工具实际结束且输出存在；记录 `qualityReviewed=false`、未测品质为 `null`。**回执**：真实输出路径和 SHA-256。**失败**：只有旧文件或缺产物，不写成功回执。

## 失败模式：原因与处置

| 症状 | 原因/检测器 | 处置 |
|---|---|---|
| 选不到配方 | 请求 id 与 `colorread.recipes` 清单不匹配 | 返回 `not_found` 和请求 id；纠正明确参数，不换成评分候选 |
| LUT 加载失败 | 文件不存在、不可读或 LUT 解析/滤镜报错 | 保留路径和工具错误；修正文件/权限，按新输出重算 |
| 强度被拒绝 | `buildChain` 检出非有限值或越过 `(0,1]` | 返回 `bad_request`；修正请求值，不隐式钳制 |
| FFmpeg 结束却无有效产物 | 非零退出、写入失败或实际规格与请求不符 | 返回技术失败；不拿原片或旧文件冒充新调色 |
| 品质指标为空 | 默认未调用显式诊断 | 记录 `null` 和未测范围，照常完成请求加工，不追加质量放行 |
