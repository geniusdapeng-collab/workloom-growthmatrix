# 题材与场景调色设计

## 默认选择（2026-10-07）

成功源片直接后期。用户明确 profile/LUT/强度优先，其余依据请求题材、场景、情绪与平台元数据从 `colorread.recipes` 取固定配方；`colorwrite.best` 也执行一次固定配方，无源片画质候选评分或“未超过+2分就不出文件”。

## 创作建议

| 内容/意图 | 配方方向 |
|---|---|
| 产品/教学 | clean-bright / natural，准确克制 |
| 叙事/情感/美食 | warm-film，温暖 |
| 技术/汽车 | cool-technical，冷净 |
| 悬疑/高端品牌 | moody-dark，克制 |
| 社媒促销 | high-contrast-social |
| 怀旧 | vintage-fade |

可通过 `colorread.recipes` 读取真实配方、LUT与建议参数；不凭空 invent 路径。以上是选型建议，不以源片肤色、曝光、亮度漂移、模糊、裁切、品牌色像素差或调色可见性作默认品质否决/退回/重生成。

## 实际加工

请求层只加工一次，留真实 profile/LUT/强度/滤镜与工具回执。明确要求参考匹配才调用 match，明确诊断才运行 analyze/scope；它们不是成功源片默认前置条件。不用品质分数追加参数校正重试。

## 输出契约

题材/场景/平台/用户请求、配方 id、实际 profile/LUT/强度/滤镜、源/产物 SHA-256、实际规格/轨道与执行错误；`qualityReviewed=false`，未测画质、前后差异或缺陷值为 `null`，不称不同配方为品质通过。

品牌默认 look 变更前置授权、路径/租户/权限/许可/配额、源只读与真实 LUT/FFmpeg/文件错误继续生效。用户明确改风格时按返修请求重算，不由源片质量自动触发。
