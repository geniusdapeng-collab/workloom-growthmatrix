# 字幕版式设计

## 当前默认（2026-10-07）

成功源片直接后期，不通过源片可读性、字号、行宽、墨迹、遮挡区或对比度品质放行。按请求参数与平台/题材元数据选配方，实际加工一次；以下是设计建议，不是品质硬闸。用户明确文字、时长、位置或样式优先，非法参数/时间轴仍按输入合同失败。

## 字号与样式建议

`字号 = 短边 × 场景基准比 × 粗细修正 × 平台倍率`；建议基准：标题 0.11、字幕 0.048、弹幕 0.04、贴纸 0.07；描边可从字号 0.06、边距从短边 0.05 起。建议不能成为默认抽帧、墨迹测量或越界品质否决。

## 平台布局建议

| 平台 | 默认配方建议 |
|---|---|
| 默认横屏 | 底部居中字幕、顶部标题 |
| 抖音/快手 | 竖屏字幕上移、避让常见底部与右侧界面 |
| B站 | 顶部留弹幕区域、底部字幕 |
| 小红书 | 标题与贴纸按题材配方 |
| 视频号 | 字号略大、字幕位置上移 |
| YouTube | 横屏字幕、标题可用左下布局 |

平台界面随版本变化，以上仅本仓配方建议；不把推断位置称为当前平台规范。显式诊断可读取源片，但默认不量亮度/细节/墨迹或强制调整请求。

## 内容与节奏

文字、事件条数与请求时间轴保留；不按行宽、密度或停留建议丢字/抽稀弹幕。ASS 自动换行与所选样式记录在方案；贴纸合法请求时长/位置可执行。卡拉OK 缺真实逐字时序时按字数均分，并标“非真实发音对齐”，不冒充口型或发音已经核验。

## 输出契约

字体 id/许可/文件摘要、请求字号/描边/边距/对齐、ASS 样式与全部事件、实际时间轴与源/产物 SHA-256；`qualityReviewed=false`，未测墨迹/对比度/可现度为 `null`。实际缺字体、非法 ASS 或时间轴（G-SUB3）明确失败，许可/品牌/配额前置约束保持，不默认品质退回或重渲染。
