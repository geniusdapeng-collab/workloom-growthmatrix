# 字幕版式设计

## 当前默认（2026-10-07）

成功源片直接后期，不通过源片可读性、字号、行宽、墨迹、遮挡区或对比度品质放行。按请求参数与平台/题材元数据选配方，实际加工一次；以下是设计建议，不是品质硬闸。用户明确文字、时长、位置或样式优先，非法参数/时间轴仍按输入合同失败。

## 字号与样式建议

`字号 = 短边 × 场景基准比 × 粗细修正 × 平台倍率`；建议基准：标题 0.11、字幕 0.048、弹幕 0.04、贴纸 0.07；描边可从字号 0.06、边距从短边 0.05 起。建议不能成为默认抽帧、墨迹测量或越界品质否决。

## 平台布局建议

| 平台 | 默认配方建议 |
|---|---|
| 默认横屏 | 底部居中字幕、顶部标题 |
| 抖音/快手 | 竖屏字幕上移、避让常见底部与右侧界面 |
| B站 | 顶部留弹幕区域、底部字幕 |
| 小红书 | 标题与贴纸按题材配方 |
| 视频号 | 字号略大、字幕位置上移 |
| YouTube | 横屏字幕、标题可用左下布局 |

平台界面随版本变化，以上仅本仓配方建议；不把推断位置称为当前平台规范。显式诊断可读取源片，但默认不量亮度/细节/墨迹或强制调整请求。

## 内容与节奏

文字、事件条数与请求时间轴保留；不按行宽、密度或停留建议丢字/抽稀弹幕。ASS 自动换行与所选样式记录在方案；贴纸合法请求时长/位置可执行。卡拉OK 缺真实逐字时序时按字数均分，并标“非真实发音对齐”，不冒充口型或发音已经核验。

## 输出契约

字体 id/许可/文件摘要、请求字号/描边/边距/对齐、ASS 样式与全部事件、实际时间轴与源/产物 SHA-256；`qualityReviewed=false`，未测墨迹/对比度/可现度为 `null`。实际缺字体、非法 ASS 或时间轴（G-SUB3）明确失败，许可/品牌/配额前置约束保持，不默认品质退回或重渲染。

## 工艺判据

| 输入情形 | 可执行版式决定 | 记录依据 |
|---|---|---|
| 横屏/竖屏画布 | 使用工程请求的 PlayRes 和实际画布，不通过抽帧推测平台安全区 | 请求分辨率、ASS PlayRes |
| 字幕/标题/弹幕/贴纸 | 从对应字号基准建议起步，明确字号覆盖建议 | 选型配方、请求值、实际样式 |
| 多行和长文字 | 保留每条全部内容，用 ASS `\N` 编码已有换行，由 libass 排版 | 原 cue 文本、ASS 事件与条数 |
| 主/次语言 | 保留各语言时间轴，选真实字体与双语样式 | 字体 id/摘要、语言、事件时间 |
| 卡拉OK | 有逐字起止就按请求；缺逐字时序则按字数均分并标明来源 | timingMode、逐字事件、非真实发音对齐标记 |
| 弹幕密集 | 保留所有合法事件，不抽稀或改写请求；记录排布方案 | 输入与输出事件条数、时间轴 |

## 参数边界

1. 时间必须可解析，起止必须满足 `end > start`；弹幕 `at` 必须是有限非负值。格式或时间合同失败时返回真实错误，不丢掉该条继续交付。
2. 字体必须真实存在、可读取且许可适用；不得用系统回落冒充请求字体。实际 fontselect 解析结果随回执记录。
3. 色值、ASS 转义与事件格式必须符合实际编码合同；禁止把原文直接拼进控制码后声称已正确排版。
4. 字号、边距、描边与平台位置建议不能变成成功源片品质否决；禁止为了满足行宽/密度建议删文字或抽稀事件。源文件只读，输出另存。

## SOP

1. **触发**：收到字幕/标题/弹幕等请求；记录完整内容、语言、合法时间轴与工程画布。**回执**：原事件条数和请求参数。**失败**：格式、倒挂或非法时间值，返回 `bad_srt`/`bad_style`，停止对应加工。
2. **触发**：内容有效；按请求或本仓配方选字体和样式，查询真实字体目录。**回执**：字体 id/许可/摘要、实际字号与 ASS 样式。**失败**：字体缺失或不可读，返回真实字体错误，不假称已用。
3. **触发**：方案完整；生成全部 ASS 事件，执行一次所请求输出。**回执**：PlayRes、事件、字体解析与真实输出摘要。**失败**：ASS/FFmpeg/存储错误明确返回，不通过删事件重试。
4. **触发**：输出实际完成；检查本次文件、时间轴、规格与原字节。**回执**：品质值 `null`、`qualityReviewed=false` 与真实文件。**失败**：缺产物或错误输出不写成功清单。

## 失败模式：原因与处置

| 症状 | 原因/检测器 | 处置 |
|---|---|---|
| 时间轴不能生成 | SRT 时间格式、倒挂或非法事件值 | 返回原条号和稳定错误；修正输入，不静默丢条 |
| 实际字体不符 | 字体文件缺失或 fontselect 显示系统回落 | 保留字体解析日志，修正真实字体目录/选择 |
| ASS 解析/渲染失败 | 色值、转义、样式或事件编码错误 | 记录 ASS 文件和工具错误；修对应编码后按新请求加工 |
| 产物不存在/写不完 | FFmpeg、权限、配额或存储失败 | 返回技术失败；不拿旧字幕或原片冒充完成 |
| 没有墨迹/对比度指标 | 默认未跑质量测量 | 如实写 `null`，不追加源片抽帧、品质裁剪或放行 |
